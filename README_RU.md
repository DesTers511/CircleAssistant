# Circle Assistant — исходный проект Android

Это стартовый проект Android Studio для ручной настройки и запуска одного кругового жеста через Android AccessibilityService.

## Открытие
1. Распакуйте архив.
2. Откройте папку `CircleAssistantAndroid` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Соберите и установите приложение на свой Android-телефон.

## Первоначальная настройка
1. В приложении задайте координаты центра X/Y, радиус в пикселях и длительность.
2. Нажмите «Сохранить настройки».
3. Включите Circle Assistant в настройках специальных возможностей Android.
4. Разрешите отображение поверх других приложений.
5. Покажите плавающую панель, затем откройте Roblox и нажмите START.

## Важные ограничения
- Координаты X/Y и радиус задаются в пикселях всего экрана; это начальная техническая версия, а не калибровка по изображению.
- Окружность начинается с правой крайней точки и идёт по часовой стрелке.
- Android AccessibilityService может не работать в некоторых играх или быть ограничен системой/игрой.
- Длительность одного жеста ограничена 60 секундами.
- Значение «точность %» сохраняется как ориентир интерфейса; оно не меняет геометрию само по себе и не гарантирует игровой процент.
- Перед использованием в игре проверьте жест в безопасном тестовом приложении. Используйте только там, где автоматизация разрешена правилами игры.


## Визуальная калибровка (обновление)
После выдачи разрешения «Показывать поверх других приложений» нажмите «Показать плавающую панель» в приложении. Теперь поверх экрана появится затемнённый режим калибровки:
- Перетаскивайте белую центральную точку, чтобы переместить центр.
- Перетаскивайте белую точку на правом краю, чтобы изменить радиус.
- «СОХРАНИТЬ» запоминает положение.
- «НАЧАТЬ» сохраняет круг, убирает калибровку и через короткую паузу запускает круговой жест.
- «ЗАКРЫТЬ» убирает режим калибровки.

Для калибровки используйте экран Roblox с видимым столом. При первом запуске проверяйте координаты и радиус осторожно: системные панели и вырезы экрана могут влиять на расположение.


## Сборка APK через GitHub Actions (без Android Studio)
1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в репозиторий всё содержимое этой папки, включая скрытую папку `.github`.
3. Откройте вкладку **Actions** репозитория.
4. Если GitHub попросит разрешить workflows, нажмите **I understand my workflows, go ahead and enable them**.
5. Запустите **Build Android APK** через **Run workflow** (или дождитесь автоматической сборки после push в main/master).
6. Откройте завершённый запуск workflow и скачайте артефакт **CircleAssistant-debug-apk** внизу страницы.
7. Распакуйте артефакт ZIP на телефоне и установите `app-debug.apk`. Android может попросить разрешить установку из этого источника.

GitHub Actions собирает debug APK, не подписанный для публикации в Google Play. Перед использованием проверьте работу на своём устройстве.
